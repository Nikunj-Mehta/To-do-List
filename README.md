# To-do List 📝

A simple **To-do List** application built using **HTML, CSS, and JavaScript** with DOM manipulation.  
This app allows you to **add tasks**, **mark them as done**, **delete individual tasks**, and even **mark all or delete all tasks** at once.

---

## Features

- **Add Tasks**  
  Quickly add tasks to your to-do list.  

- **Mark as Done**  
  Click a task to mark it as done; completed tasks will have a line through them.  

- **Delete Tasks**  
  Remove individual tasks or clear the entire list at once.  

- **Mark All / Delete All**  
  Manage multiple tasks efficiently with single-click options.

- **Interactive UI**  
  Clean and simple interface to manage your tasks easily.

---

## How to Use

1. Open `index.html` in your browser.  
2. Enter a task in the input box and click **Add**.  
3. Click on a task to mark it as done.  
4. Use the **Delete** button to remove a task.  
5. Use **Mark All** or **Delete All** to manage all tasks at once.
